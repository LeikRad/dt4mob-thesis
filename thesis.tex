\Abstract{palavras-chave}{gémeo digital, Unreal Engine, visualização 3D, dados geoespaciais, infraestrutura, código aberto.}
         {resumo}{\selectlanguage{portuguese}Os sistemas de digital twin para infraestruturas físicas são tipicamente desenvolvidos como aplicações fechadas e especializadas, acopladas a um único tipo de infraestrutura e a um único fornecedor de dados. Este trabalho apresenta um visualizador de digital twins de código aberto, construído sobre a Unreal Engine, desenhado para ser generalizável a diferentes tipos de infraestrutura e desacoplado do backend de dados que alimenta a cena. Descreve-se a arquitetura da aplicação, as decisões tomadas ao longo do desenvolvimento para alcançar essa generalização e desacoplamento, e os resultados obtidos.\\Este documento não incide sobre o Eclipse Ditto, backend usado para validar o visualizador durante o desenvolvimento, que é objeto de outros trabalhos.}

\Abstract{keywords}{digital twin, Unreal Engine, 3D visualization, geospatial data, infrastructure, open source.}
         {abstract}{\selectlanguage{english}Digital twin systems for physical infrastructure are typically built as closed, purpose-specific applications, tightly coupled to a single infrastructure type and a single data backend. This work presents an open-source digital twin viewer built on Unreal Engine, designed to generalize across different infrastructure types and to be decoupled from the data backend feeding the scene. The application's architecture is described, along with the decisions made throughout development to achieve this generalization and decoupling, and the results obtained.\\This document does not focus on Eclipse Ditto, the backend used to validate the viewer during development, which is the subject of other work.}
